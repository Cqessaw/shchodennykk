# Щоденник

Електронний шкільний щоденник: розклад уроків, домашні завдання, оцінки 1–12.
Одна сторінка без бекенду — працює у браузері на комп'ютері й на телефоні, у тому числі офлайн.

## Що вміє

- **Тижнева сітка** з реальним розкладом уроків, підсвіченим сьогоднішнім днем.
- **Домашні завдання** для кожного уроку: додати, редагувати, позначити виконаним, видалити.
- **Автоматичні дедлайни.** Застосунок знає розклад, тому рахує, коли наступний урок цього
  предмета, і підписує «здати до Ср». Прострочене підсвічується червоним.
- **Панель «Найближче»** — що треба здати найраніше, з переходом на потрібний день.
- **Оцінки 1–12** з кольорами за рівнями і середнім балом по кожному предмету.
- **Резервні копії** — експорт та імпорт усіх даних одним JSON-файлом.
- **PWA** — встановлюється на телефон як окремий застосунок і працює без інтернету.

## Спільні домашні завдання

Кнопка **«Спільний режим»** внизу сторінки. Усі, хто ввів однаковий код класу,
бачать спільний список ДЗ, який оновлюється наживо: додав завдання на одному
телефоні — воно за секунду з'явилося в решти.

- Дані кімнати лежать у Firestore за шляхом `rooms/{код}/homework/{дата}-{урок}`.
- Захист — це сам код кімнати: хто його знає, той може читати й редагувати.
  Правила доступу лежать у консолі Firebase (Firestore → Rules) і додатково
  перевіряють структуру запису та довжину тексту.
- Ключі проєкту в `index.html` — публічні ідентифікатори, а не паролі; у веб-застосунках
  вони завжди відкриті, а доступ обмежують саме правила.

**Оцінки в кімнату не потрапляють ніколи** — вони особисті й лишаються лише на пристрої.

## Де зберігаються дані

Домашні завдання — у `localStorage` браузера, а якщо ввімкнено спільний режим, то ще й
у Firestore. Оцінки — завжди тільки в `localStorage`. Наслідки:

- без спільного режиму пристрої **не синхронізуються** — для перенесення
  використовуй «Зберегти копію» / «Відновити з копії»;
- очищення даних сайту в браузері видалить локальні записи, тому час від часу роби копію;
- на iOS застосунок з іконки має окреме сховище від Safari — це не помилка.

## Встановити на телефон

1. Відкрити сторінку в Chrome (Android) або Safari (iOS).
2. Android: меню ⋮ → **Встановити застосунок**.
   iOS: кнопка «Поділитися» → **На екран «Домівка»**.
3. Далі відкривається з іконки як звичайний застосунок, інтернет не потрібен.

## Запустити локально

Достатньо відкрити `index.html` подвійним кліком. Service worker при цьому не працює
(потрібен `http(s)://`), решта функцій — так.

## Змінити розклад

Розклад заданий константою `SCHEDULE` в `index.html`: ключі `1`–`5` це Пн–Пт,
у кожному дні масив уроків `{n: номер, s: "Предмет", sub: "підпредмет"}`.
Урок, якого немає, просто не вказується.

## Оновити застосунок після змін

Сайт збирається з гілки `gh-pages`, тому оновлювати треба обидві:

```bash
git add -A
git commit -m "Оновлення"
git push origin main main:gh-pages
```

Якщо змінював `index.html` або `sw.js`, підніми версію кешу в `sw.js`
(`shchodennyk-v2` → `shchodennyk-v3`), щоб телефон підтягнув нову версію.
